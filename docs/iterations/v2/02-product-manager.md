# V2 产品经理方案

> V2 定位：让用户从"在这里起草，去别处完成"变成"在这里完成，直接发布"

---

## V1 复盘关键洞察

超过 70% 的活跃用户仍需将项目导出到剪映或 Premiere 做最终处理。最高频的三个跳出原因：多平台适配、转场质感、多素材管理。

V2 核心命题不是加新功能，而是**封死"跳出去"的理由**。

---

## P0-1：多平台自适应渲染引擎

**每周节省 6-8 小时，竞品剪映已部分解决——不做就留不住用户。**

| 层级 | 能力 |
|------|------|
| 基础层 | 智能裁切引擎（YOLO 主体检测 + 关键帧裁切 + 线性插值） |
| 编排层 | 布局适配规则（各比例独立的字幕安全区、标题位置） |
| 叙事层 | 竖屏节奏微调（自动缩短单镜头时长） |
| 交互层 | 三画布预览（一次编辑，同时预览三种比例） |

**交付标准：** 一键生成 9:16 和 1:1 版本，90% 无需手动调整。

---

## P0-2：进阶转场系统

**成片质感的核心感知因素，技术风险低、ROI 极高。**

**V2.0 交付：**
- 8 种通用转场：推入/推出、滑动、缩放、旋转、擦除、交叉溶解
- 基于 FFmpeg xfade filter
- 时长（0.3-1.5s）和缓动曲线可配

**V2.1 交付：**
- 自定义转场模板（GLSL/Lottie）
- 品牌转场包
- AI 推荐转场（根据前后 clip 内容语义）

---

## P1-1：跨片段语义理解

**Phase 1：** CLIP embedding 视觉相似度聚类（低成本、快速）
- 素材自动分组
- 跨 clip 指令（"所有产品特写放第二段"）
- 重复/相似 clip 检测

**Phase 2（V2.1）：** VLM 结构化标签 → 素材知识图谱

---

## P1-2：基础色彩工具

- 自动白平衡统一（多机位色温对齐）
- 6 个预设 LUT：电影感、清新、复古、高对比、日系、赛博朋克
- 亮度/对比度/饱和度手动调节

---

## P2（本版本）

- Ken Burns 效果（静态图片慢推/慢拉/平移）
- 多模型 Provider 抽象层（架构预留）

---

## 成功指标

| 指标 | V1 基线 | V2 目标 |
|------|---------|---------|
| 跳出到外部工具 | ~70% | < 25% |
| 单视频多平台分发耗时 | 3x | 1.2x |
| 无需外部后处理比率 | ~30% | > 75% |
| 素材整理时间 | 30min+ | < 5min |
