# FireRed-OpenStoryline 版本迭代规划

> 本目录包含从 V0 到 V6 的持续迭代文档，由四个角色（用户、产品经理、研发、测试）分别产出。

---

| 版本 | 核心主题 | 用户群体 |
|------|----------|----------|
| **V0** | 现状：能跑通的 Demo | — |
| **V1** | 从"一次性生成"到"可迭代编辑" | 个人创作者 |

```
docs/iterations/vN/

├── 02-product-manager.md # 产品经理：优先级与方案设计

└── 04-tester.md          # 测试：测试策略与用例
```

## 迭代流程

每次迭代按以下顺序进行：
1. **用户 + 产品经理先行**：用户从自身视角提需求，PM 从产品层次设计方案
2. **研发提供技术方案**：数据结构、架构变更、文件变更、工时估算
3. **测试提出测试方案**：测试用例、边界情况、性能基准、风险补充
4. **研发根据测试反馈优化**：迭代改进技术方案
