# V1 用户视角 — 大V自媒体创作者需求

> 角色: 小红书50万粉美食探店博主，每周产出3-4条视频

---

## 最致命的问题：改一个小地方就要全部重跑

这是我最崩溃的。比如我让AI剪了一条3分钟的探店视频，整体结构和节奏都不错，但是我想把第二段和第三段换个顺序，或者中间某句配音语速太快想重新生成——结果要从头跑一遍整个流程？等十几分钟出来的东西可能别的地方又变了。这在实际工作中是不可接受的。我用CapCut手动拖一下就几秒钟的事。

**如果V1只能做一件事，就做这个：让我能局部修改，不要全量重跑。**

## 没有记忆，不懂我的风格

我每条视频的开头都有固定的"嗨大家好我是XX"的intro，结尾都有固定的关注引导，中间的转场风格也是统一的。但V0每次都像第一次见我一样，我得反复描述这些。一个真正好用的工具应该记住我的风格模板——我的字幕字体、我的常用BGM风格、我的视频节奏偏好。

## 出片质量离发布标准有差距

MoviePy渲染出来的东西，说实话，质量感不够。字幕样式太基础，转场效果几乎没有，画面调色也做不了。我的粉丝对画面质感是有预期的，直接发出去会掉粉。现在出来的东西我还得拖进CapCut再精修一遍，那这个工具的意义在哪？

## 不能边看边改

我希望能看到一个时间线预览，哪怕是粗糙的，让我能指着某个片段说"这里换一下"、"这段太长了裁短一点"。现在是黑盒操作——我说一句话，等很久，出来一个结果，不满意再说一句话，再等很久。这个交互效率太低了。

## 多平台适配

我同时在小红书（竖屏9:16）、B站（横屏16:9）和抖音发内容。同一条素材我需要快速出不同比例的版本，不是简单裁切，是要重新构图的。这个如果能自动化，每周能省我大概3-4个小时。

## 需求优先级

1. **局部修改能力**（不全量重跑）——没这个就不可能日常用
2. **风格记忆/模板**——让效率真正超过手动编辑
3. **实时预览+可视化时间线**——让交互效率及格
4. **渲染质量提升**——让成片达到可发布标准
5. **多平台比例适配**——锦上添花但省时间
