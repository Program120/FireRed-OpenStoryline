## 角色 A：MCN 机构运营总监（管理 30+ 达人账号）

### 1. 最致命的问题：没有团队协作，规模化生产全靠吼

我们机构有 30 多个达人账号，每周总产出超过 100 条视频。现在的工作流是：编导写完脚本发微信给剪辑师，剪辑师用 OpenStoryline 生成初版，导出发给达人审片，达人在微信语音里说"第三段不行"，剪辑师再改——**整个协作链全在工具外面**。

我需要的是：编导、剪辑师、达人三个角色能在同一个项目里协作。编导写指令，剪辑师精修，达人一键审批或标注修改意见。不需要 Google Docs 级别的实时协同，但**至少要有项目级别的多人访问、评论、版本历史**。

### 2. 品牌合规检查靠人肉，出事就是大问题

我们接品牌广告，品牌方对画面内容有严格要求：竞品 logo 不能出现、特定用语不能使用、产品展示时长有最低要求。现在全靠编导和法务人肉审片，每周至少漏过 2-3 个合规问题。上个月有一条视频里闪过了竞品包装，品牌方直接扣了我们 5 万违约金。**我需要 AI 自动扫描成片，标记潜在的品牌安全问题。**

### 3. 不知道哪条视频效果好、为什么好

30 个账号发了上千条视频，哪些封面点击率高、哪些开头留人、哪种节奏完播率好——这些数据散落在各个平台后台。我需要一个地方看到：这条视频用了什么剪辑策略、那条视频换了什么风格之后数据变好了。**A/B 测试能力是刚需**——同一条素材出两个版本的封面和开头，看哪个跑得好。

### 4. 缺少 B-roll，素材永远不够用

达人拍的素材经常不够覆盖脚本内容。比如讲到"全球变暖"需要一个冰川融化的画面，讲到"经济数据"需要一个股票走势的动态图。现在要么买版权素材（贵），要么用静态图片凑（丑）。听说 VACE 和 Open-Sora 2.0 已经能生成不错的短视频片段了，**如果能直接在剪辑流程里调用 AI 生成 B-roll，每条视频至少省 20 分钟找素材时间。**

### 5. 想要 API 接口做自动化流水线

我们有一些固定模板的视频（日报、周报、产品上新），内容结构完全一样，只是数据和素材不同。我希望后端系统直接通过 API 调用 OpenStoryline 批量生成，不需要人坐在界面前操作。**SDK/API 是规模化生产的基础设施。**

## 角色 B：个人创作者（50 万粉美食博主，V1 以来的老用户）

### 1. AI 生成 B-roll 太让人期待了

我做美食探店，经常需要一些氛围画面——清晨的菜市场、热气腾腾的厨房、食材的微距特写。拍摄当天不一定能全部覆盖，如果 AI 能根据我的脚本自动补充这些空镜头，成片完整度会好很多。但**画面风格必须和我的实拍素材一致**，不能一眼看出是 AI 生成的。

### 2. 封面和标题的 A/B 测试

每次发视频最纠结的就是封面选哪张、标题怎么写。如果能自动生成 3-5 个封面方案，配合不同标题，发出去之后看数据自动选最优的，这个功能我愿意付费。

### 3. 视频项目的版本管理

改来改去经常改废了想回退到之前某个版本，现在只能靠手动备份。我需要类似 git 那样的版本历史，能随时回到任意一个历史状态。

### 4. 插件生态

我有一些自己的小需求，比如每次发布前自动在视频最后 3 秒加上固定的二维码贴片。这种个性化需求不可能官方都做，如果有插件机制让社区或者我自己写脚本来扩展就好了。

## 需求优先级（MCN 视角权重更高）

1. **团队协作 + 多人项目管理** — 没有这个，MCN 客户不会买单
2. **AI 生成 B-roll（VACE/Open-Sora 集成）** — 两个角色都高度需要
3. **内容合规 / 品牌安全检查** — MCN 的法律风险刚需
4. **数据分析 + A/B 测试** — 规模化运营的核心决策依据
5. **API/SDK** — 自动化流水线的基础
6. **视频项目版本控制** — 提升个人和团队的迭代效率
7. **自动封面生成** — 高频需求，技术可行性高
8. **插件/扩展生态** — 长期价值，降低定制开发压力
