# V5 产品经理方案

> V5 定位：从"AI 剪辑助手"升级为"AI 创意总监"——系统不仅执行指令，还能自主提出创意方向、从数据中学习、持续优化创作策略

---

## V4 复盘关键洞察

V4 交付了团队协作、AI 生成素材、API/SDK、插件生态、版本控制、合规检查六大模块。当前用户画像已从个人创作者扩展到 MCN 机构。核心数据：

- 日均渲染任务峰值 500+，MCN 客户占 60%
- 用户最高频的反馈集中在"选题太依赖人"和"没有数据反馈"
- 跳出到外部工具的比例已降至 ~15%，但音频后处理仍是主要跳出原因
- 竞品 UniVA 的 Plan-and-Act 架构 + 三层记忆系统正在快速追赶

V5 核心命题：**把 AI 的角色从"听命令的执行者"提升为"有主见的创意合伙人"**。

## P0-1：自主创意引擎（Creative Direction Engine）

**解决"谁来想选题"的问题——MCN 创意总监每周花 15+ 小时在选题调研上。**

### 子模块 A：实时趋势分析

| 能力 | 说明 |
|------|------|
| 多平台热点抓取 | 抖音/B站/小红书/YouTube/微博热搜、热门话题、飙升关键词 |
| 行业垂类监控 | 按账号所属垂类（美妆/科技/美食...）过滤相关趋势 |
| 趋势窗口预测 | 基于历史热点生命周期预测"现在跟还来不来得及" |
| 竞品内容追踪 | 监控指定竞品账号的发布内容和数据表现 |

### 子模块 B：AI 选题推荐

每日自动生成选题推荐卡片：
```
[选题推荐 #3] 热度: 8.5/10  契合度: 9/10  时效: 48h
标题方向：「2026 防晒新品盲测：实验室数据 vs 真人户外 8 小时」
推荐理由：#防晒测评 话题 24h 内搜索量涨 320%，你的账号历史上"实测对比"类内容平均完播率比均值高 45%
脚本框架：开箱(15s) → 实验室指标对比(30s) → 户外实测(60s) → 结论排名(20s)
素材需求：产品开箱 × 5, 实验室B-roll × 3, 户外实拍 × 8
参考爆款：[链接] 320w播放
```

### 子模块 C：概念到成片的自主推进

用户确认选题后，系统自主完成：选题展开 → 脚本细化 → 素材需求清单 → 现有素材匹配 + 缺失素材标注 → 生成/采购缺失素材 → 初剪 → 自检 → 提交审核。

**中间每个关键节点可人工介入，但默认自动推进。**

**交付标准：** 从选题确认到初剪提交，无人值守时间 > 80%。

## P0-2：数据驱动优化引擎（Performance Learning Engine）

**解决"剪完没有反馈"的问题——让系统从 600 条/月的数据中学习。**

### Phase 1：数据采集与归因

| 数据维度 | 来源 | 用途 |
|----------|------|------|
| 完播率/互动率/分享率 | 各平台 API / 手动导入 | 核心优化目标 |
| 观众流失曲线 | 抖音创作者后台 | 定位具体流失时间点 |
| 剪辑特征向量 | 内部提取 | 节奏(BPM)、转场密度、字幕占比、BGM能量曲线、前3秒hook类型 |
| A/B 测试标签 | 用户标注 / 自动匹配 | 同内容不同剪法的对比 |

### Phase 2：模式发现与策略建议

- 自动聚类高表现视频的共性特征（如"前3秒悬念 + 1.2x 节奏 + 暖色调 = 高完播"）
- 生成账号级别的"创作策略报告"（周/月）
- 在剪辑过程中实时提示"根据历史数据，建议在这里加一个转场"

### Phase 3：自动应用

- 新项目自动继承该账号的最优剪辑策略作为默认参数
- Planner 在决策时参考历史表现数据
- 效果差的模式自动降权

**交付标准：** 使用数据优化引擎的账号，月均完播率提升 > 15%。

## P0-3：高级音频生成套件

**封死音频后处理的最后跳出原因。**

### 声音克隆

- 输入：5-10 分钟高质量音频样本
- 输出：可用于任意文案的 TTS 声音
- 技术：GPT-SoVITS / CosyVoice 2
- 安全：需声音所有者授权确认，克隆结果带水印

### AI 配乐生成

- 输入：视频时长 + 情绪曲线 + 风格标签（如"轻快电子 + 120BPM"）
- 输出：原创无版权 BGM，自动对齐视频节拍点
- 技术：Stable Audio / MusicGen
- 交互：支持"这段副歌再激昂一点"的迭代修改

### 音效合成

- 基于画面内容自动生成匹配音效（环境音、动效、强调音）
- VLM 识别画面元素 → 音效标签 → 音效生成/检索

**交付标准：** 音频后处理跳出率从 30% 降至 < 5%。

| 能力 | 说明 |
|------|------|
| 剪辑模式提取 | 从历史项目中提取可复用的"剪辑模式"（节奏模板、转场组合、字幕风格） |

## P2-1：国际化

- Prompt 模板全面英文化（已有 en/ 目录，补全覆盖）
- 多语言 TTS 支持（英/日/韩/西班牙语）
- 多语言字幕自动翻译 + 本地化排版
- 各地区平台适配规则（YouTube Shorts / TikTok / Instagram Reels）

---

## P2-2：移动端轻量编辑

- 核心能力：素材上传 + 粗剪预览 + 审片批注 + 语音指令编辑
- 技术方案：WebView 封装 + 后端渲染（不在端侧跑模型）
- 高级能力（Phase 2）：端侧小模型做实时预览滤镜 + 粗剪

---

## P2-3：创意市场（Marketplace）

- 模板商店：转场包、字幕模板、LUT 预设、剪辑模式模板
- 技能商店：社区贡献的 Skill（如"电商口播模板"、"旅行 Vlog 模板"）
- 收益分成：创作者上传模板/技能 → 其他用户付费使用 → 创作者获得分成
- 审核机制：质量评分 + 人工审核 + 合规扫描
