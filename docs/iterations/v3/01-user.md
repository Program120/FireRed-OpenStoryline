## 身份 A：百万粉博主（V1/V2 老用户）

### 1. 我被锁死在一个模型上了

V2 用得很舒服，但我的 API 账号是 Claude 的，你们底层只支持 OpenAI 兼容接口。我试过换 Gemini 做视觉理解（因为它 token 便宜且长上下文强），换不了。另外有些任务用 Qwen 更便宜，配音理解用 Claude 更好——我想让不同 node 走不同模型。**每月 API 费用大概 800 块，如果能混合调度估计能省 40%。**

### 2. 我需要导出给合作方做精修

越来越多品牌合作方要求我提供 Premiere XML 或达芬奇 EDL 工程文件，方便他们的后期团队在此基础上微调。现在我只能导出最终 MP4，合作方改不了就得从头剪。这直接影响我接商单的效率——**一条品牌合作视频因为不能交 XML，沟通返工多出 2-3 天。**

### 3. 配音情感太机械

TTS 生成的语音语调平得像念稿机器。我做美食探店需要"兴奋感"，做科技评测需要"冷静专业感"，做 vlog 需要"随性聊天感"。现在只能选声音不能选情感风格，出来的效果粉丝一耳朵就听出是AI，影响内容信任度。

### 4. 长视频我不敢用

素材超过 15 分钟以后明显卡顿，CLIP 嵌入计算巨慢，渲染动不动超时。我偶尔要做 30-60 分钟的直播回放剪辑、活动合集，这类内容完全没法在现有系统里做。

## 身份 B：MCN 机构运营总监（新用户，管理 15 个达人账号）

### 1. 批量操作是刚需中的刚需

我们每周要为 15 个达人发布 40-50 条短视频。很多视频的片头片尾、品牌水印、字幕风格是统一的，但现在每条视频都要单独操作。**我需要"选中 20 条视频 → 统一加片头 + 统一字幕模板 + 统一 LUT"这种批量流水线。**

### 2. 谁在用、改了啥、我怎么审

15 个达人 + 3 个剪辑师同时在用，没有任何权限管理、操作日志、审批流程。达人自己改了参数我不知道，剪辑师用了什么 LUT 我看不到。MCN 需要：项目级权限（查看/编辑/发布）、操作审计日志、发布前审批。

### 3. 哪条视频表现好我不知道

每条视频发出去后表现如何，跟剪辑参数之间完全割裂。我想知道"用了电影感 LUT + 0.5s 转场的竖屏视频，平均完播率比其他高 12%"这种洞察，好让团队复制成功模式。

## 需求优先级（合并两个身份）

1. **多模型 Provider 支持 + 混合调度** —— 省钱 + 解锁更多模型能力
2. **批量处理流水线** —— MCN 核心生产力
3. **导出 NLE 格式（XML/EDL）** —— 打通专业协作
4. **配音情感/风格精细控制** —— 内容质感最后一块短板
5. **团队协作（权限 + 审计 + 审批）** —— MCN 管理基本盘
6. **长视频性能优化** —— 解锁新内容品类
7. **数据分析闭环** —— 锦上添花但能建立壁垒
