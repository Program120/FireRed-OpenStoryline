# V3 产品经理方案

> V3 定位：从"个人创作者的 AI 剪辑助手"升级为"MCN 级 AI 视频生产平台"

---

## V2 复盘关键洞察

- 跳出到外部工具比率从 70% 降至约 22%，符合预期。**剩余 22% 集中在：需要 NLE 协作（8%）、配音不够自然（7%）、长视频性能（4%）、其他（3%）**。
- 新增 MCN 试用用户 3 家，核心反馈一致：**没有批量操作和团队权限，根本无法在机构内推开**。
- API 成本投诉上升——用户量增长后，单一模型绑定的成本劣势被放大。

V3 核心命题：**横向扩品类（长视频、批量）+ 纵向打通协作链路（NLE 导出、团队）**，同时用多模型支持降低用户成本门槛。

---

## P0-1：多模型 Provider 抽象层 + 混合路由

**用户痛点排名 #1，V2 已做架构预留，现在必须交付。**

| 能力 | 说明 |
|------|------|
| Provider 注册 | 统一接口适配 OpenAI / Anthropic / Google Gemini / 通义千问 / 本地 Ollama |
| Node 级路由 | 每个 Node 可配独立 provider+model（如 UnderstandClips 走 Gemini，GenerateScript 走 Claude） |
| 自动 fallback | 主模型超时/限流时自动切备用模型，最多 2 级 |
| 成本看板 | 按 session / node / model 统计 token 用量和费用 |

**交付标准：** 用户在 config 里配 3+ 个 provider，指定 node→model 映射，系统自动路由 + fallback。

---

## P0-2：批量处理流水线

**MCN 用户转化的 gate keeper。没有这个，机构用户无法付费。**

| 能力 | 说明 |
|------|------|
| 模板定义 | 将一次完整编辑流程保存为"编辑模板"（含 node 参数快照） |
| 批量应用 | 选择多个 session / 素材文件夹，一键套用模板 |
| 队列管理 | 并发控制、优先级、进度面板、失败重试 |
| 差异化覆盖 | 单条视频可在模板基础上覆盖部分参数 |

**交付标准：** 20 条视频批量套用同一模板，平均单条耗时不超过单独处理的 1.3x（并发加速），失败率 < 5%。

---

## P1-1：NLE 导出（FCP XML / DaVinci EDL）

**打通"AI 剪辑→专业精修"的最后一公里。**

- 导出 Final Cut Pro XML（FCPXML 1.11）和 DaVinci Resolve EDL
- 包含：时间线、片段引用、转场类型 + 时长、字幕轨、LUT 标记、音频轨
- 素材路径可配（本地绝对路径 / 相对路径 / 媒体打包 zip）

**不含：** FFmpeg 特有的 filter 效果无法 1:1 映射时，标注 `<!-- unsupported: ... -->` 注释。

---

## P1-2：配音情感与风格控制

| 能力 | 说明 |
|------|------|
| 情感标签 | 兴奋、平静、专业、随性、紧张、温暖 6 种 |
| 语速控制 | 0.7x ~ 1.5x 可调 |
| 段落级情感 | 不同段落可设不同情感标签 |
| Provider 适配 | 将情感标签映射到各 TTS 厂商的原生 SSML/参数 |

---

## P2-1：团队协作基础

- 项目级角色：Owner / Editor / Viewer
- 操作审计日志（who / when / what）
- 发布前审批流（Editor 提交 → Owner 审批 → 发布）
- 基于现有 Session 模型扩展，不引入重量级 RBAC

---

## P2-2：长视频性能优化

- CLIP 嵌入分片计算（每 5min 一批，流水线并行）
- 渲染分段合并（segment-level 渲染 → 最终 concat，避免全量内存）
- 30 分钟素材端到端耗时目标：< 15 分钟（当前 > 40 分钟）

---

## P3（记录但不进 V3 scope）

- 可视化时间线编辑器（需要全新前端架构，V4 规划）
- AI 自动精彩片段 / 预告片生成
- 自定义 GLSL/Lottie 转场 + 品牌包
- VLM 素材知识图谱（Phase 2）
- AI 转场推荐
- 实时协同编辑
- 数据分析集成（预测视频表现）
- AI 生成 B-roll

---

## 成功指标

| 指标 | V2 基线 | V3 目标 |
|------|---------|---------|
| 跳出到外部工具 | ~22% | < 10% |
| MCN 机构月活跃 | 3 (试用) | 10+ (付费) |
| 单条视频 API 成本 | 基线 | 降 30%+ |
| 批量处理效率（20 条） | 20x 单条 | 1.3x 单条 |
| NLE 导出可用率 | 0% | > 85% 可在 FCP/DaVinci 直接打开 |
| 30min 素材端到端耗时 | > 40min | < 15min |
